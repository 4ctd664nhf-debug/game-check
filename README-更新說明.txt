每日自律 PWA v3.1：任務數量上限可自訂

修改檔案（覆蓋原站點相同檔名即可）：
- app.js
- index.html
- style.css
- service-worker.js

不需要變更（請保留原站上的既有設定及資源）：
- push-config.js（請勿以未設定的範本覆蓋既有 Worker 網址）
- manifest.json
- icons 目錄

使用方法：
1. 更新前，在舊版 App 的「資料管理」先匯出備份。
2. 把本次 4 個修改檔案放到原網站同一目錄，並重新部署。
3. 重新開啟 App（必要時重新整理頁面以取得最新的 Service Worker 快取）。
4. 打開「資料管理」→「任務數量設定」。
5. 選擇 20/30/50/100、自訂數量或「不限項數」，按「儲存任務設定」。

新版預設：不限任務數量；既有任務與歷史紀錄不會因修改上限而刪除。
如果將上限改成低於現有任務的數量，舊任務會保留，但無法再新增，直到提高上限或刪除部分任務。
新舊備份都可匯入超過 20 項任務；新備份會包含 taskLimit 設定。
「提醒事項」仍為最多 30 則，並未在此次變更。

「不限項數」是指程式不設硬性數量上限，實際容量仍受瀏覽器儲存空間與裝置效能限制。
如果網址/網域、瀏覽器或安裝位置改變，原本 IndexedDB 資料不一定會一起轉移，請使用 JSON 備份還原。
